# 实验五：单周期 MIPS CPU

## 实验目的

在 FPGA 上造一台能真正跑 MIPS 指令的 CPU：支持加减逻辑、加载存储、分支跳转和停机，**一个时钟周期干完一条指令**。

## 支持的 15 条指令

| 类型 | 指令 | opcode / funct |
| --- | --- | --- |
| R 型 | `add` `sub` `and` `or` `slt` `sll` | `000000` / `20 22 24 25 2a 00` |
| I 型运算 | `addi` `andi` `ori` | `08` `0c` `0d` |
| 访存 | `lw` `sw` | `23` `2b` |
| 分支 | `beq` `bgtz` | `04` `07` |
| 跳转 | `j` | `02` |
| 停机 | `halt` | `3f` |

助记符沿用课程的 `src1 src2 tar`：`src1`/`src2` 只读，`tar` 只写。`sll` 的被移位数在 rt 字段，目标在 rd 字段。

## 模块结构

```
PC ──> 指令存储器 ──> Control ──> 寄存器堆 / ALU / 数据存储器 ──> 写回
 └── 下一地址三选一：PC+4 / 分支目标 / 跳转目标
```

| 文件 | 作用 |
| --- | --- |
| `pc.v` | 程序计数器，halt 时停止更新 |
| `instr_mem.v` | `$readmemh` 装载 `program.hex`，按地址取 32 位指令 |
| `control.v` | 组合译码，直接输出全部控制信号与源操作数选择 |
| `regfile.v` | 32×32 寄存器堆，0 号恒为 0 |
| `alu.v` | 加减、与或、slt、sll、gtz |
| `sign_extend.v` | 符号/零扩展立即数 |
| `data_mem.v` | 数据存储器，读组合、写同步 |
| `mux2.v` | 参数化二选一（写回数据、ALU 操作数） |
| `cpu.v` | 顶层，把上面零件连成一条组合链 |

### 与原归档库的差别

原仓库 `SingleCPU/SingleCPU.v` 顶层实例化了 `CU` 并逐位连接控制信号，但 `Control.v` 输出的是 32 位 `MicroInstruct`，接口对不上、编译不过。本仓库重写时让单周期版的控制信号**逐位直出**，多周期版才使用微指令字（见 `lab06`），两个工程都能编译通过并跑通测试。

另外，寄存器堆的写入必须放在**同一个时钟上升沿**（非阻塞赋值），不能放在下降沿：下降沿到来时 PC 已经指向下一条指令，会把它的一条指令的 ALU 结果写进本条指令的目标寄存器。

## 测试程序

`program.hex` 共 22 条指令，覆盖全部 15 种操作，并用 `beq` / `bgtz` 跳过两条不该执行的 `addi`，用 `j` 跳过停机前的顺序执行。最终预期：

- `$3=8`、`$4=2`、`$5=1`、`$6=7`、`$7=1`、`$8=20`
- `$10=4`、`$12=8`、`$13=42`（99 被跳过）、`$14=1`（77 被跳过）、`$15=100`
- `mem[0]=8`，`halt` 置 1 且 PC 停在 `0x54`

## 验证

```bash
iverilog -g2012 -o sim.out *.v && vvp sim.out
```

全部通过时打印 `lab05 PASS: single-cycle CPU executed all 15 instructions`。
