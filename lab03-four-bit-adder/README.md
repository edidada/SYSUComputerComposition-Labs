# 实验三：四位二进制数加法

## 实验目的

1. 实现四位二进制加法，给出 CF（进位）和 OF（溢出）标志；
2. 用按键切换数码管显示"两个输入"还是"结果"；
3. 熟悉七段数码管动态扫描。

## 设计

| 模块 | 作用 |
| --- | --- |
| `adder4.v` | 四位**先行进位**加法器，CF/OF 用组合逻辑直接算 |
| `mux2.v` | 8 位二选一，切换显示输入 `{a,b}` 或结果 `{0000,sum}` |
| `button_debounce.v` | 两个按键消抖，左键显示输入、右键显示结果 |
| `clk_div.v` | 100MHz → 扫描时钟（仿真用 4 分频） |
| `seven_seg.v` | 4 位数码管动态扫描，低电平有效 |

### 先行进位

普通行波进位像多米诺骨牌，一位算完才传下一位。这里用产生信号 `G = a & b` 和传递信号 `P = a ^ b` 把每一位的进位**并行算出来**：

```verilog
wire c1 = g[0];
wire c2 = g[1] | (p[1] & c1);
wire c3 = g[2] | (p[2] & c2);
wire c4 = g[3] | (p[3] & c3);
assign sum = p ^ {c3, c2, c1, 1'b0};
assign cf  = c4;
assign of  = c3 ^ c4;
```

`OF = 次高位进位 xor 最高位进位` 是判断有符号溢出的标准方法。本实现采用标准定义：**CF = 无符号加法进位输出，OF = 有符号溢出**。

- `1100 + 0100 = 10000`（即 -4 + 4 = 0）：结果 `0000`，CF=1，OF=0（有符号运算没有溢出）。
- `1100 + 1000 = 10100`（即 -4 + (-8) = -12）：结果 `0100`，CF=1，OF=1（超出四位有符号范围）。

> 原报告把"结果超出四位无符号范围"叫作溢出，并把两个灯的语义描述得比较口语化；这里按教科书定义区分 CF 和 OF，测试台也是按这个定义穷举比对的。

