# 实验六：多周期 MIPS CPU

## 实验目的

同一套 15 条 MIPS 指令，改成多周期实现：一条指令分成若干时钟周期完成，每个周期只做一件事，**同一个 ALU 被所有指令复用**。原课程说明：完成"多周期 CPU + 乘法器"即可取得相当于完成流水线的实验分数。

## 5 个状态（独热码）

```
10000 → IF   取指
01000 → ID   译码 / 读寄存器
00100 → EX   执行（ALU 复用）
00010 → MEM  访存
00001 → WB   写回
```

`Stage.v` 会**按需跳过**不需要的周期：微指令字的 `[31]` 表示要不要访存周期、`[30]` 表示要不要写回周期。

- R 型运算：`IF → ID → EX → WB`（跳过 MEM）
- `lw`：`IF → ID → EX → MEM → WB`（全走）
- `beq` / `bgtz` / `j`：`IF → ID → EX`（既不访存也不写回）

## 32 位微指令字

`Control.v` 把一条指令翻译成一个 32 位控制字，硬件按位取用：

| 位段 | 用途 |
| --- | --- |
| `[31]` | 需要访存周期 |
| `[30]` | 需要写回周期 |
| `[29]` | 停机 |
| `[28:25]` | ALU 操作码 |
| `[24:23]` / `[22:21]` | ALU 左右操作数来源 |
| `[20]` | 写内存使能 |
| `[19]` | 写回选内存数据 |
| `[18:17]` | 分支类型（beq / bgtz） |
| `[16]` | 跳转使能 |

在 `cpu.v` 里，微指令在 ID 周期锁存到 `micro_ex`，后续 EX / MEM / WB 都按这个字行动——这就是"控制字"的硬核实现。

## 与单周期版共用的部件

`pc.v`、`instr_mem.v`、`regfile.v`、`alu.v`、`sign_extend.v`、`data_mem.v`、`mux2.v`、`program.hex` 与 `lab05` 完全一致，**只换了控制方式和数据通路时序**。测试程序也相同，所以两个 CPU 的最终寄存器和内存结果必须逐项相等——这是很强的交叉验证。

## 验证

```bash
iverilog -g2012 -o sim.out *.v && vvp sim.out
```

测试台跑 120 个周期，检查全部 15 条指令的执行结果、`sw` 写入的内存、以及最终停在 IF 状态的 `halt`。全部通过打印 `lab06 PASS: multi-cycle CPU executed all 15 instructions`。
