# 实验二：按键计数 + 数码管显示

## 实验目的

每按一次按键，数字加 1，在七段数码管上显示；快速连按时不能乱跳。这是"多个模块拼起来"的第一个练习。

## 模块结构

顶层 `top.v` 是一张接线图，把 4 个零件连起来：

| 模块 | 作用 |
| --- | --- |
| `clk_div.v` | 分频，把几十 MHz 板载时钟降到人眼能看见的扫描速度 |
| `button_debounce.v` | 三级触发器消抖，取上升沿输出单周期脉冲 |
| `counter.v` | 看到脉冲就 `q <= q + 1` |
| `seven_seg.v` | 16 位数字动态扫描到 4 位数码管，段码/位码均低电平有效 |

### 消抖的关键

```verilog
shift <= {shift[1:0], btn_in};
if (shift == 3'b111) level <= 1'b1;
else if (shift == 3'b000) level <= 1'b0;
assign btn_pulse = level & ~prev_level;
```

按键信号像排队一样存三拍，只有连续三拍稳定为高才认账；再取上升沿，保证一次按下只产生一个脉冲。机械按键按下时"哆嗦"几毫秒，这个电路把抖动过滤掉了。

## 验证

```bash
iverilog -g2012 -o sim.out *.v && vvp sim.out
```

测试台检查：复位归零、数码管位选确实轮流扫描、一次干净按下计 1、一次带毛刺的按下也只计 1、第三次按下计 3。全部通过时打印 `lab02 PASS`。

> 上板时把顶层参数 `DISP_DIV` 改成 100000 量级；仿真为了快，默认是 4。
