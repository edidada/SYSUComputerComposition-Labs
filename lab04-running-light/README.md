# 实验四：流水灯（可调速 / 换向 / 暂停 / 复位）

## 实验目的

16 盏灯依次点亮，像跑马灯一样；通过开关调速度、换方向、暂停、复位。这是课程里第一个真正有交互设计的实验。

## 模块结构

| 模块 | 作用 |
| --- | --- |
| `clk_div.v` | 可调速分频，`BASE >> speed` 决定分频比，共四档速度 |
| `direction.v` | 三个物理开关 → 两位方向码 |
| `light_decode.v` | 位置编号 0~15 → 16 位独热灯形 |
| `top.v` | 在分频时钟下更新位置，处理绕回 |

### 两位方向码

| Dir | 含义 |
| --- | --- |
| `00` | 保持不动（暂停） |
| `01` | 复位到最左 |
| `10` | 向左递减 |
| `11` | 向右递增 |

状态更新时显式处理绕回：向右到 15 后回 0，向左到 0 后回 15，所以灯跑到头不会卡死。

> 上板时把 `BASE` 改成 12500000 左右（100MHz 时钟下约 0.125 秒走一步）；仿真用 32 跑得快。

## 验证

```bash
iverilog -g2012 -o sim.out *.v && vvp sim.out
```

测试台检查：复位归零、向右递增、暂停保持、向左递减并绕回、复位开关、四种方向码编码、灯形为独热码。全部正确打印 `lab04 PASS`。
