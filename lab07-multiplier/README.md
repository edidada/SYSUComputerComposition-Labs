# 实验七：8×8 移位相加乘法器

## 实验目的

用拨码开关输入两个 8 位数，用硬件一步一步算出 16 位乘积，数码管显示结果。这是课程最后一个专项运算实验。

## 核心算法：手算二进制乘法的硬件版

`multiply.v` 是一个 3 状态机：

```text
IDLE (00)：等待 start，result=0, temp=乘数, extend={0,被乘数}
RUN  (01)：循环 8 次
    如果 temp[0] 为 1：result += extend
    temp 右移一位，extend 左移一位
DONE (10)：product <= result，done 拉高一个周期
```

跟在纸上手算一模一样：看乘数当前位，是 1 就把被乘数（已左移到对应位置）加到结果里。**每个周期算一位，8 个周期出结果**——用时间换硬件面积。

## 顶层外设

| 模块 | 作用 |
| --- | --- |
| `button_debounce.v` | 按键消抖，一个上升沿一个脉冲 |
| `switch.v` | 翻转开关：按一次显示输入，再按一次显示结果 |
| `clk_div.v` | 数码管扫描分频 |
| `seven_seg.v` | 4 位数码管动态扫描 |
| `multiply.v` | 核心乘法器 |
| `top.v` | 把上述零件连起来，`sw[15:8]` 被乘数、`sw[7:0]` 乘数；两盏 LED 指示显示模式 |
